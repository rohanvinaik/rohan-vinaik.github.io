The four pillars

One paradigm — geometric navigation through a constrained space — instantiated four times across model search, theorem proving, code specification, and mutation testing. Same encoding move, different domain.

ModelAtlas

ml-model-search // semantic anchors // no gpu

Google for HuggingFace's 800K models. 29,657 indexed, 166 semantic anchors, <100ms queries on a SQLite file — zero neural inference at query time.

Wayfinder

lean 4 // proof compiler // 22m params

Proof compiler for Lean 4. 63% of a 2,000-theorem random Mathlib sample in one pass on commodity hardware; 28% requires no trained model at all. Matches DeepSeek-Prover-V2 (671B, datacenter) on AIME-from-MiniF2F-test, on a laptop.

LintGate

specification compiler // mc/dc // mutation

Specification compiler. 100% mutation kill on a 30K-model codebase, MC/DC verification-capable, DO-178C Level A. Debugging drops to zero under supervision. The question it answers: how many tests does it take to fully specify a program?

Wesker

mutation testing // python ast // zero deps

In-process AST mutation testing for Python — 100–500x faster than mutmut or cosmic-ray. ~1,770 lines, zero dependencies. Mutation testing has been "too expensive to use" for 48 years; Wesker restructures the computation.

Earlier work

The four pillars grew out of three research threads, plus a set of applied projects. Each is its own working artifact; together they're the lineage that produced the paradigm.

Verification — can we identify a model through behavior alone?
PoT_Experiments · cryptographic model identity via behavioral fingerprints, 90.9% on a Mac for ~$0.50 of electricity. REV · neural-network "restriction sites" — verify 70B models in 3–4 GB of memory. HBT_Validator · hyperdimensional fingerprints capturing architectural lineage (Behavioral Holography, 95.8% with 256 API calls).
Grounding — can we explain what a model knows, and why it's wrong?
semantic_probing · 62 NSM primitives, Hadamard-orthogonal, 100% routing precision, 273µs per query, no training. sparse-wiki-grounding · typed knowledge links with explicit reasoning chains — when an LLM hallucinates, this tells you why and who actually did the misattributed thing.
Alignment — can we guarantee what a system won't do?
orthogonal-validators · structurally independent decompositions; 0% error rate on auto-accepted outputs. negative-learning · Minsky's censors and suppressors — 22x more sample-efficient than positive examples. experience-memory · O(1) fix lookup for recurring errors, ~1.6µs retrieval, no gradient descent.
Applied
ShortcutForge · natural-language compiler for Apple Shortcuts; LLM output as untrusted intermediate code. GenomeVault · privacy-preserving genomics on a Z₂×Z₂ + HDC + reference-pool stack; 99.978% accuracy at 30 MB / 5.81 µs. Yami · the Wayfinder thesis applied to chess: 6 cheap signals, interference pattern is the move.
Foundations
Kanerva (hyperdimensional computing) · Wierzbicka (semantic primitives) · Minsky (censors, suppressors, K-lines) · Collins & Loftus (spreading activation) · Winston (near-miss learning).

About

the person behind the patterns

I'm a biochemist who taught himself formal methods. Same move shows up in everything I build: find the geometry of the problem, navigate it, let cheap search handle the rest. The four pillars above are that move done four times — different domains, same paradigm.

The substrate is the lever. DNA hands you orthogonal binary structure for free if you encode it right. HuggingFace's 800K models cluster by anchor signature if you stop trying to embed them. Theorem space has navigable structure if you stop trying to predict the next token. Code specification has minimum complexity if you stop measuring coverage and start measuring the program directly.

Independent researcher. Cambridge, MA. The work has no institutional scaffolding behind it; it's also reproducible from a laptop, which is part of the bet.

The legibility infrastructure — peer-reviewed papers, talks, citations — is mostly downstream of work that hasn't been written up yet. The Lean proofs compile, the Kaggle medals are real, the metrics reproduce, but the formal write-ups that make the work portable across institutions are the next thing. If you find a piece of the work that interests you, email me. That's the fastest path.
