# RohanV.me

Personal research website, published by GitHub Pages from `main` at the repository root.

The console uses separate static HTML pages, JetBrains Mono, and ordinary page navigation. No frontend build is required.

The live paper feed calls the existing Cloudflare discovery worker directly; its CORS policy allows `https://rohanv.me`. The worker and daily paper-archive workflow remain separate from the frontend.

Previous website versions are linked from `archive/`. The version replaced on 2026-10-17 is also preserved by the Git tag `archive/pre-console-2026-10-17`.
